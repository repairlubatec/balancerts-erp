BALANCERTS.ERP — REORGANIZAÇÃO DA
INTERFACE DE CONTABILIDADE
OBJETIVO
Reorganizar completamente a interface do módulo Contabilidade para eliminar a necessidade de fazer
scroll vertical para encontrar e executar os trabalhos contabilísticos.


A imagem atual mostra:


     • Empresa ativa no topo;
     • Exercício;
     • Período;
     • Botão "Alterar contexto";
     • Os trabalhos contabilísticos ficam abaixo da área visível.

Isso deve ser alterado.


O contabilista deve conseguir:


selecionar Empresa → Ano → Período → visualizar imediatamente as operações disponíveis


sem sair da empresa e sem precisar procurar os trabalhos através de scroll.




1. EMPRESA, ANO E PERÍODO DEVEM SER O
CONTEXTO PRINCIPAL
Manter no topo da página uma barra de contexto compacta.


Estrutura:



  ┌──────────────────────────────────────────────────────────────────────┐
  │ Empresa: Repair Lubatec ▼            Ano: 2026 ▼        Período: Agosto ▼         │
  └──────────────────────────────────────────────────────────────────────┘


Todos os campos devem ser selecionáveis diretamente.


Não utilizar uma página separada para mudar o exercício.


Não obrigar o contabilista a sair da empresa.

REGRA FINAL
O contabilista deve conseguir selecionar Empresa, Ano e Período diretamente no topo e,
imediatamente depois, visualizar e executar os trabalhos contabilísticos daquele contexto.


Não obrigar o utilizador a:


      • sair da empresa;
      • abrir outra página para trocar o ano;
      • abrir outra página para trocar o período;
      • fazer scroll para descobrir as operações;
      • voltar repetidamente ao topo;
      • utilizar "Alterar contexto" para operações normais.

Implementar a alteração preservando todas as funcionalidades existentes.


Antes de alterar o código, analisar a arquitetura atual de contexto financeiro, exercício, período,
permissões e navegação para garantir que a mudança visual não quebra a lógica contabilística
existente.


Depois da implementação, testar:


      1. trocar 2026 → 2025;
      2. trocar Agosto → Setembro;
    3. trocar empresa;
    4. abrir lançamentos;
    5. voltar;
    6. abrir documentos;
    7. voltar;
    8. confirmar que Empresa + Ano + Período permanecem corretos;
    9. testar período fechado;
   10. testar exercício encerrado;
   11. testar permissões de utilizador.

A prioridade é:
